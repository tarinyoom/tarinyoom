# Hi, I'm Adam

I'm a software engineer interested in computer graphics, numerical methods, and scientific computing. I enjoy building software from first principles, particularly where mathematics meets real-time systems.

### Pomelo
I'm currently working on Pomelo, an interactive 3D incompressible fluid simulation implementing Jos Stam's Stable Fluids method. Also inspired by [Chapter 38 of GPU Gems](https://developer.nvidia.com/gpugems/gpugems/part-vi-beyond-triangles/chapter-38-fast-fluid-dynamics-simulation-gpu. It currently simulates N smoke sources rising as plumes.

### SPH
A previous project involved writing a 2D incompressible fluid simulation using a method called Smoothed Particle Hydrodynamics (SPH) solver in the browser using Rust compiled to Wasm, runnable directly in the browser at https://sph.tarinyoom.io/. I stopped work on this due to challenges in parallelizing SPH's neighbor search.
